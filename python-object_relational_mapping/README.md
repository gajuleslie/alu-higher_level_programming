# Python - Object-relational mapping

This project connects Python to MySQL with `MySQLdb` and SQLAlchemy.

## Tasks 0-5: MySQLdb

The first scripts connect to MySQL on localhost port 3306 and query the
`hbtn_0e_0_usa` and `hbtn_0e_4_usa` databases. They cover selecting, filtering,
safe parameterized queries, joins, and comma-separated city output.

## Tasks 6-14: SQLAlchemy ORM

`model_state.py` maps the `states` table and `model_city.py` maps the `cities`
table. The remaining scripts create sessions, query objects, insert, update,
and delete rows without writing SQL queries directly.
