# Python - More Classes and Objects

This project continues object-oriented programming in Python: properties,
string representations, instance counters, class attributes, static methods,
and class methods.

## Tasks

### 0. Simple rectangle
`0-rectangle.py` defines an empty `Rectangle` class.

### 1. Real definition of a rectangle
`1-rectangle.py` defines a `Rectangle` with private, validated `width` and
`height` properties.

### 2. Area and Perimeter
`2-rectangle.py` adds `area()` and `perimeter()` methods.

### 3. String representation
`3-rectangle.py` adds `__str__`, which draws the rectangle with `#`.

### 4. Eval is magic
`4-rectangle.py` adds `__repr__` so `eval(repr(rectangle))` recreates it.

### 5. Detect instance deletion
`5-rectangle.py` prints `Bye rectangle...` from `__del__`.

### 6. How many instances
`6-rectangle.py` adds the `number_of_instances` class attribute.

### 7. Change representation
`7-rectangle.py` adds the `print_symbol` class attribute.

### 8. Compare rectangles
`8-rectangle.py` adds the `bigger_or_equal` static method.

### 9. A square is a rectangle
`9-rectangle.py` adds the `square` class method.
