# Python - Classes and Objects

This project introduces object-oriented programming in Python: defining
classes, private instance attributes, properties, and instance methods.

## Tasks

### 0. My first square
`0-square.py` defines an empty `Square` class.

### 1. Square with size
`1-square.py` defines a `Square` with a private `__size` attribute.

### 2. Size validation
`2-square.py` validates that `size` is an integer greater than or equal to 0.

### 3. Area of a square
`3-square.py` adds an `area()` method that returns the square's area.

### 4. Access and update private attribute
`4-square.py` adds a `size` property with a validated setter.

### 5. Printing a square
`5-square.py` adds `my_print()`, which prints the square using `#`.

### 6. Coordinates of a square
`6-square.py` adds a validated `position` property and prints the square at
the given offset.
