# Python - More Data Structures

This project covers Python sets, dictionaries, and matrix operations.

## Tasks

### 0. Squared simple
`0-square_matrix_simple.py` has a function `square_matrix_simple(matrix=[])`
that returns a new matrix with every value squared, without modifying the
original matrix.

### 1. Search and replace
`1-search_replace.py` has a function `search_replace(my_list, search, replace)`
that returns a new list with every occurrence of `search` replaced by `replace`.

### 2. Unique addition
`2-uniq_add.py` has a function `uniq_add(my_list=[])` that adds all unique
integers in a list, counting each integer only once.

### 3. Present in both
`3-common_elements.py` has a function `common_elements(set_1, set_2)` that
returns a set of the elements present in both sets.

### 4. Only differents
`4-only_diff_elements.py` has a function `only_diff_elements(set_1, set_2)`
that returns a set of all elements present in only one of the two sets.

### 5. Number of keys
`5-number_keys.py` has a function `number_keys(a_dictionary)` that returns the
number of keys in a dictionary.

### 6. Print sorted dictionary
`6-print_sorted_dictionary.py` has a function
`print_sorted_dictionary(a_dictionary)` that prints a dictionary by ordered
keys.

### 7. Update dictionary
`7-update_dictionary.py` has a function
`update_dictionary(a_dictionary, key, value)` that replaces or adds a
key/value pair in a dictionary.

### 8. Simple delete by key
`8-simple_delete.py` has a function `simple_delete(a_dictionary, key="")`
that deletes a key from a dictionary when it exists.

### 9. Multiply by 2
`9-multiply_by_2.py` has a function `multiply_by_2(a_dictionary)` that returns
a new dictionary with all values multiplied by 2.

### 10. Best score
`10-best_score.py` has a function `best_score(a_dictionary)` that returns the
key with the biggest integer value, or `None` when no score is found.

### 11. Multiply by using map
`11-multiply_list_map.py` has a function
`multiply_list_map(my_list=[], number=0)` that returns a new list with every
value multiplied by `number`, using `map`.

### 12. Roman to Integer
`12-roman_to_int.py` has a function `roman_to_int(roman_string)` that converts
a Roman numeral to an integer, returning 0 when the input is not a string.
